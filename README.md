# KimiStudio-
KumiStudio es una cabina para fotografiar y grabar objetos pequeños con luz controlada: componentes de computador, coleccionables, joyas, artículos usados para vender en línea. El objeto gira sobre un plato, cuatro torres de luz lo iluminan y una cámara 4K lo captura. Todo se maneja desde el celular, sin instalar aplicaciones.
